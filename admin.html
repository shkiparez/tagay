Админка сайта «Тагай»

Для входа нужен ключ доступа GitHub к репозиторию сайта. Пароль на сайте не хранится — без ключа изменить сайт невозможно.

  1. Откройте github.com → Fine-grained token
  2. Repository access → Only select repositories → tagay
  3. Permissions → Repository → Contents: Read and write
  4. Нажмите «Generate token» и вставьте ключ сюда
